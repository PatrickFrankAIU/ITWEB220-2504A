## What This Project Does

This repository serves as an interactive learning platform for **ITWEB-220: Introduction to Web Development** students. It provides a structured, hands-on approach to learning JavaScript fundamentals through practical exercises and coding challenges.

### Purpose & Functionality

**Educational Learning Platform:**
- Provides 28+ progressive JavaScript exercises covering fundamental to intermediate concepts
- Offers hands-on coding practice with immediate application of learned concepts
- Facilitates individual student progress tracking through GitHub collaboration

**Course Structure:**
- **Module 1**: JavaScript basics (variables, input/output, arithmetic, string manipulation)
- **Module 2**: Control structures (if/else, loops, arrays, functions, advanced logic)

**Learning Progression:**
The exercises progress from simple concepts like:
- Basic input/output with `prompt()` and `console.log()`
- Variable declarations and arithmetic operations
- String manipulation and character access

To more advanced programming concepts:
- Conditional logic and branching (if/else, switch-case, ternary operators)
- Iteration and loops (for, while, forEach)
- Array manipulation and functional programming
- Complex algorithms (FizzBuzz, nested conditionals)

**Student Workflow Management:**
- Each student maintains their own workspace within the repository
- Organized folder structure for exercise submissions
- Version control integration for tracking progress and receiving feedback

### Technical Implementation

**Exercise Structure:**
Each exercise consists of:
- `index.html` - Basic HTML page that loads the JavaScript
- `main.js` - JavaScript implementation of the exercise solution

**Example Exercise Topics:**
- **Basic Calculations**: Temperature conversion, age to days conversion, item pricing
- **User Interaction**: Input validation, personality quizzes, text-based adventures
- **Logic & Control Flow**: Traffic light decisions, grade classification, nested conditionals
- **Loops & Iteration**: Counting exercises, mathematical calculations, pattern generation
- **Arrays & Functions**: Sales tax calculation, greeting generation, data processing

**Repository Organization:**
```
ITWEB220-2504A/
├── README.md (this file)
├── Mod1Exr/ (example exercise)
│   ├── index.html
│   └── main.js
└── [Student Name Folders]/
    └── [Exercise Name Folders]/
        ├── index.html
        └── main.js
```

## Student Instructions 
- Accept the collaborator invite (check your email) 
- Clone this repository to your local computer
- Add some text to the readme file that's located in the folder with your name on it
- Commit and sync the changes
- Advise the instructor that you're finished
- Note: These steps are also listed in the first Issue, titled "Join and Clone (Do This First)" (all the way at the bottom of the issue list)

**Tips:**
- Avoid changing anything in another student's folder -- this makes it harder for them to get feedback from the instructor
- Please **DO NOT** mark the issue "complete" -- this makes it impossible for other students to see the issue

**Procedure:**
- For each issue that you work on, create a separate folder *within* the folder with our name on it 
- Name this new folder after the Issue's Title 
- Then create an index.html and main.js file within each of these folders, demonstrating the solution to the Issue 
- Please **DO NOT** mark the issue "complete" -- this makes it impossible for other students to see the issue
